# Персональний помічник

Консольний застосунок для керування **контактами** та **нотатками**.
Усе відбувається в командному рядку: ви вводите команду, програма її виконує
й чекає наступну, доки не введете `exit`.

Дані зберігаються на диску, тож після перезапуску контакти й нотатки на місці.

---

## Можливості

**Контакти**
- Додавання контакту з полями: ім'я, прізвище, адреса, телефон, email,
  день народження, тег з `#` (наприклад, `#друзі`).
- Редагування окремого поля і видалення контакту.
- Пошук по всіх полях (включно з цифрами телефону).
- Сортування (групування) контактів за тегом.
- Список контактів, у яких день народження через задану кількість днів.

**Нотатки**
- Створення, редагування, видалення нотатки.
- Теги з `#` на початку, наприклад `#робота #ідеї`.
- Пошук по нотатках і пошук за конкретним тегом.
- Групування нотаток за тегами.
- Прив'язка нотатки до контакту і перегляд нотаток контакту.

**Перевірка введення**
- Телефон приймається лише в міжнародному форматі `+380(XX)XXX-XX-XX`.
  Код `+380` можна не вводити: досить 9 цифр або `0XXXXXXXXX`.
- Email, дата (`ДД.ММ.РРРР`, не в майбутньому), імена (лише літери),
  теги нотаток і контактів (з `#`).
- Автовиправлення: ім'я і прізвище з малої літери стають з великої
  (`анна` → `Анна`, `коваль-шевченко` → `Коваль-Шевченко`).
  Номер без коду країни (`501234567`) доповнюється до `+380...`.
  Кожне автоматичне виправлення програма показує повідомленням.
- Некоректне значення не закриває програму: вона пояснює помилку і просить
  ввести значення ще раз.

## Встановлення

Потрібен Python 3.10 або новіший.

### Варіант 1. Як Python-пакет (рекомендовано)

Так програма запускається командою `assistant` з будь-якої папки системи.

```bash
# 1. Перейдіть у папку проєкту
cd personal-assistant

# 2. Створіть віртуальне оточення
python3 -m venv .venv

# 3. Активуйте його
#    Linux / macOS (bash, zsh):
source .venv/bin/activate
#    Linux (fish):
source .venv/bin/activate.fish
#    Windows (PowerShell):
.venv\Scripts\Activate.ps1

# 4. Встановіть пакет
pip install .

# 5. Запустіть застосунок
assistant
```

Щоб запускати `assistant` без активації оточення, встановіть пакет
у системний `pipx`:

```bash
pipx install /шлях/до/personal-assistant
assistant
```

### Варіант 2. Без встановлення

З папки проєкту:

```bash
python3 -m personal_assistant
```

## Запуск з будь-якого місця

Найзручніший варіант: встановити пакет через `pipx`. Тоді команда `assistant`
працює з будь-якої папки, без активації віртуального оточення.

```bash
# Один раз: встановлення (з папки проєкту або з повного шляху)
pipx install /home/m/personal-assistant

# Після цього з будь-якої папки:
cd ~
assistant
```

Оновлення після змін у коді:

```bash
pipx install --force /home/m/personal-assistant
```

### Коротка команда `pa` (fish)

Щоб запускати програму коротким словом `pa`, додайте в fish alias на
команду `assistant`. Не на `python3 -m personal_assistant`: той варіант
працює лише з папки проєкту.

```fish
# Для поточної сесії
alias pa assistant

# Назавжди: додайте той самий рядок у ~/.config/fish/config.fish
```

Якщо alias `pa` уже вказує на `python3 -m personal_assistant`, замініть його.

## Де зберігаються дані

За замовчуванням файл даних: `~/.personal_assistant/data.pkl`.

Щоб використати інший файл, задайте змінну середовища `PA_DATA_FILE`:

```bash
PA_DATA_FILE=/шлях/до/моїх_даних.pkl assistant
```

Дані записуються після кожної зміни (додавання, редагування, видалення).
Запис іде через тимчасовий файл, тому збій під час збереження не псує
вже збережені дані.

## Використання

Після запуску введіть команду і відповідайте на запитання програми.

| Команда | Скорочення | Що робить |
|---------|------------|-----------|
| `add-contact` | `a` | Додати контакт |
| `contacts` | `l` | Показати всі контакти |
| `edit-contact` | `e` | Змінити одне поле контакту |
| `delete-contact` | `d` | Видалити контакт (з підтвердженням) |
| `search-contact` | `s` | Пошук контактів по всіх полях |
| `sort-contacts` | `g` | Контакти, згруповані за тегом |
| `birthdays` | `b` | Контакти, у яких день народження через N днів (0 — сьогодні) |
| `add-note` | `na` | Додати нотатку (можна одразу прив'язати до контакту) |
| `notes` | `nl` | Показати всі нотатки |
| `edit-note` | `ne` | Змінити заголовок, текст, теги або прив'язку нотатки |
| `delete-note` | `nd` | Видалити нотатку (з підтвердженням) |
| `search-note` | `ns` | Пошук нотаток |
| `find-tag` | `nt` | Нотатки з конкретним тегом, наприклад `#робота` |
| `sort-notes` | `ng` | Нотатки, згруповані за тегами |
| `contact-notes` | `nc` | Нотатки, прив'язані до контакту |
| `help` | `h` | Список команд |
| `exit` | `q` | Вихід |

Повні назви теж працюють, скорочення — лише зручність.

Скорочення для нотаток мають префікс `n`: `na`, `nl`, `ne`, `nd`, `ns`, `nt`, `ng`, `nc`.

### Приклад сесії

```text
Команда: add-contact
Ім'я: Анна
Прізвище: Коваль
Адреса: Київ, вул. Хрещатик, 1
Телефон (+380(XX)XXX-XX-XX): 123
Помилка: Некоректний номер. Використовуйте формат +380(XX)XXX-XX-XX. Спробуйте ще раз.
Телефон (+380(XX)XXX-XX-XX): 0501234567
Тег контакту (наприклад, сім'я або робота): друзі
Email (Enter — пропустити): anna@example.com
День народження ДД.ММ.РРРР (Enter — пропустити): 05.03.1990
Контакт додано.

Команда: add-note
Заголовок: Подарунок
Текст нотатки: Купити книгу
Теги з # (наприклад, #робота #ідеї) (Enter — пропустити): #побут #ідеї
Ім'я контакту для прив'язки (Enter — без прив'язки): Анна Коваль
Нотатку додано:
[1] Подарунок
    Купити книгу
    Теги: #побут #ідеї
    Контакт: Анна Коваль
```

### Зміна імені, прізвища та телефону

Команда `edit-contact` (або `e`):

1. Введіть повне ім'я контакту, наприклад `Анна Коваль`.
2. Програма покаже картку контакту і пронумерований список полів.
3. Введіть номер поля:
   - `1` — ім'я;
   - `2` — прізвище;
   - `4` — телефон.
4. Введіть нове значення. Порожній Enter залишає поле без змін.

Приклад зміни телефону:

```text
Команда: e
Повне ім'я контакту (Ім'я Прізвище): Анна Коваль
...
Номер поля (Enter — скасувати): 4
Нове значення для «Телефон (+380(XX)XXX-XX-XX)» (Enter — без змін): 671112233
Виправлено автоматично: номер без коду країни: додано +380 автоматично
Контакт оновлено.
```

Що важливо знати:
- Телефон вводиться в міжнародному форматі, але код `+380` можна не писати:
  достатньо 9 цифр (`671112233`) або `0671112233`.
- Ім'я і прізвище автоматично стають з великої літери.
- Якщо змінити ім'я або прізвище, нотатки, прив'язані до цього контакту,
  переходять на нове ім'я.
- Не можна змінити ім'я так, щоб збіглося з уже наявним контактом. Програма
  покаже помилку і нічого не змінить.

### Поради

- Пропуск необов'язкового поля — порожній Enter.
- Щоб прибрати email або день народження при редагуванні, введіть `-`.
- У `edit-contact` і `edit-note` Enter без значення залишає поле без змін.
- Тег контакту пишеться з `#` на початку, одним словом: `#друзі`, `#сім'я`.
  Теги контактів і нотаток виводяться синім кольором.
- Теги виводяться синім кольором. Колір вимикається, якщо вивід іде у файл
  або задано змінну `NO_COLOR` (наприклад, `NO_COLOR=1 assistant`).
- Кирилиця вводиться в UTF-8 або cp1251. Якщо термінал надсилає інше
  кодування, програма покаже помилку; у такому разі змініть кодування
  терміналу на UTF-8.
- Щоб вийти з дії посеред введення, натисніть `Ctrl+C`. Програма повернеться
  до списку команд.

## Запуск тестів

Тести написані стандартним модулем `unittest`, зовнішніх залежностей не треба.
Запуск з папки проєкту:

```bash
python3 -m unittest -v
```

Тести не чіпають ваші справжні дані: вони працюють з тимчасовими файлами.
