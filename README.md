# Персональний помічник

Консольний застосунок для керування **контактами** та **нотатками**.
Усе відбувається в командному рядку: ви вводите команду, програма її виконує
й чекає наступну, доки не введете `exit`.

Дані зберігаються на диску, тож після перезапуску контакти й нотатки на місці.

---

## Можливості

**Контакти**
- Додавання контакту з полями: ім'я, прізвище, адреса, телефон, email,
  день народження, тег.
- Редагування окремого поля і видалення контакту.
- Пошук по всіх полях (включно з цифрами телефону).
- Сортування (групування) контактів за тегом.
- Список контактів, у яких день народження через задану кількість днів.

**Нотатки**
- Створення, редагування, видалення нотатки.
- Теги з `#` на початку, наприклад `#робота #ідеї`.
- Пошук по нотатках і пошук за конкретним тегом.
- Групування нотаток за тегами.
- Прив'язка нотатки до контакту і перегляд нотаток контакту.

**Перевірка введення**
- Телефон приймається лише в міжнародному форматі `+380(XX)XXX-XX-XX`.
  Код `+380` можна не вводити: досить 9 цифр або `0XXXXXXXXX`.
- Email, дата (`ДД.ММ.РРРР`, не в майбутньому), імена (лише літери),
  теги нотаток (з `#`).
- Некоректне значення не закриває програму: вона пояснює помилку і просить
  ввести значення ще раз.

## Встановлення

Потрібен Python 3.10 або новіший.

### Варіант 1. Як Python-пакет (рекомендовано)

Так програма запускається командою `assistant` з будь-якої папки системи.

```bash
# 1. Перейдіть у папку проєкту
cd personal-assistant

# 2. Створіть віртуальне оточення
python3 -m venv .venv

# 3. Активуйте його
#    Linux / macOS (bash, zsh):
source .venv/bin/activate
#    Linux (fish):
source .venv/bin/activate.fish
#    Windows (PowerShell):
.venv\Scripts\Activate.ps1

# 4. Встановіть пакет
pip install .

# 5. Запустіть застосунок
assistant
```

Щоб запускати `assistant` без активації оточення, встановіть пакет
у системний `pipx`:

```bash
pipx install /шлях/до/personal-assistant
assistant
```

### Варіант 2. Без встановлення

З папки проєкту:

```bash
python3 -m personal_assistant
```

## Де зберігаються дані

За замовчуванням файл даних: `~/.personal_assistant/data.pkl`.

Щоб використати інший файл, задайте змінну середовища `PA_DATA_FILE`:

```bash
PA_DATA_FILE=/шлях/до/моїх_даних.pkl assistant
```

Дані записуються після кожної зміни (додавання, редагування, видалення).
Запис іде через тимчасовий файл, тому збій під час збереження не псує
вже збережені дані.

## Використання

Після запуску введіть команду і відповідайте на запитання програми.

| Команда | Скорочення | Що робить |
|---------|------------|-----------|
| `add-contact` | `ac` | Додати контакт |
| `contacts` | `lc` | Показати всі контакти |
| `edit-contact` | `ec` | Змінити одне поле контакту |
| `delete-contact` | `dc` | Видалити контакт (з підтвердженням) |
| `search-contact` | `sc` | Пошук контактів по всіх полях |
| `sort-contacts` | `gc` | Контакти, згруповані за тегом |
| `birthdays` | `bd` | Контакти, у яких день народження через N днів (0 — сьогодні) |
| `add-note` | `an` | Додати нотатку (можна одразу прив'язати до контакту) |
| `notes` | `ln` | Показати всі нотатки |
| `edit-note` | `en` | Змінити заголовок, текст, теги або прив'язку нотатки |
| `delete-note` | `dn` | Видалити нотатку (з підтвердженням) |
| `search-note` | `sn` | Пошук нотаток |
| `find-tag` | `ft` | Нотатки з конкретним тегом, наприклад `#робота` |
| `sort-notes` | `gn` | Нотатки, згруповані за тегами |
| `contact-notes` | `cn` | Нотатки, прив'язані до контакту |
| `help` | `h` | Список команд |
| `exit` | `q` | Вихід |

Повні назви теж працюють, скорочення — лише зручність.

### Приклад сесії

```text
Команда: add-contact
Ім'я: Анна
Прізвище: Коваль
Адреса: Київ, вул. Хрещатик, 1
Телефон (+380(XX)XXX-XX-XX): 123
Помилка: Некоректний номер. Використовуйте формат +380(XX)XXX-XX-XX. Спробуйте ще раз.
Телефон (+380(XX)XXX-XX-XX): 0501234567
Тег контакту (наприклад, сім'я або робота): друзі
Email (Enter — пропустити): anna@example.com
День народження ДД.ММ.РРРР (Enter — пропустити): 05.03.1990
Контакт додано.

Команда: add-note
Заголовок: Подарунок
Текст нотатки: Купити книгу
Теги з # (наприклад, #робота #ідеї) (Enter — пропустити): #побут #ідеї
Ім'я контакту для прив'язки (Enter — без прив'язки): Анна Коваль
Нотатку додано:
[1] Подарунок
    Купити книгу
    Теги: #побут #ідеї
    Контакт: Анна Коваль
```

### Поради

- Пропуск необов'язкового поля — порожній Enter.
- Щоб прибрати email або день народження при редагуванні, введіть `-`.
- У `edit-contact` і `edit-note` Enter без значення залишає поле без змін.
- Щоб вийти з дії посеред введення, натисніть `Ctrl+C`. Програма повернеться
  до списку команд.

## Запуск тестів

Тести написані стандартним модулем `unittest`, зовнішніх залежностей не треба.
Запуск з папки проєкту:

```bash
python3 -m unittest -v
```

Тести не чіпають ваші справжні дані: вони працюють з тимчасовими файлами.
